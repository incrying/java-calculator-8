# java-calculator-precourse

### 구현 예정 기능

- [x]  입출력
    - 문자열 입력받기
    - 결과 출력하기
- [x]  구분자 관리
    - 커스텀 구분자가 있는지 확인
    - 있을 경우 등록, 없으면 기본 구분자로 진행
- [x]  입력 나누기
    - 커스텀 구분자가 있는 경우, 구분자 정의 부분과 숫자 부분 분리
    - 없는 경우, 입력 그대로 반환
- [x]  숫자 관리
    - 등록된 구분자에 따라 숫자를 추출
- [x]  계산
    - 덧셈 수행
- [x]  예외 처리
    - 사용자의 입력 오류에 대한 IllegalArgumentException
